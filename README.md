# Bot Warfare Configs

Personal collection of [Bot Warfare](https://github.com/ineedbots/bot_warfare) mod configs for every Call of Duty title I run on Steam Deck — Plutonium (T4, T5, T6, IW5) and IW4X (MW2 2009). Each file auto-loads a specific bot count, skill level, and loadout setup so matches start pre-configured without typing console commands every time.

## Files

| File | Game | Client |
|---|---|---|
| `t4-botwarfare-config.cfg` | World at War | Plutonium |
| `t5-botwarfare-config.cfg` | Black Ops | Plutonium |
| `t6-botwarfare-config.cfg` | Black Ops 2 | Plutonium |
| `iw5-botwarfare-config.cfg` | Modern Warfare 3 | Plutonium |

## What the settings do

- `bots_manage_fill` — total match size to maintain (bots + you)
- `bots_manage_fill_mode 0` — fill counts bots and players together toward that total
- `bots_manage_fill_kick` — whether to kick bots if the lobby goes over the fill target
- `bots_skill` — `0` = random skill per bot
- `bots_skill_min` — floor on that randomization (T4 only, set to `4` so bots never roll too easy)
- `bots_loadout_rank 0` / `bots_loadout_prestige -2` — randomizes bot rank/prestige instead of matching yours
- `ragdoll_max_simulating` — caps simultaneous ragdolls (lowered on T4/T5 to help frame rate on Deck)

## Install — Plutonium (T4 / T5 / T6 / IW5)

Plutonium reads these as `seta` dvars, executed automatically from each game's own player profile — no exec command needed.

1. Open the Plutonium storage folder. On this Deck it's symlinked at `~/Desktop/Plutonium (Drive C)/`, or directly at:
   `~/.local/share/Steam/steamapps/compatdata/2275433825/pfx/drive_c/users/steamuser/AppData/Local/Plutonium/storage/`
2. Go into the folder for the game you're installing (`t4`, `t5`, `t6`, or `iw5`) → `players/`
3. Copy the matching config from this repo into that folder as **`plutonium_mp.cfg`**, replacing the existing one.
4. Restart the client (or just reload to main menu) so the profile re-reads.

> **T6 caution:** `t6-botwarfare-config.cfg` is not a small bot-only snippet — it's a full engine-generated profile (`// generated by Plutonium, do not modify`) that happens to also carry the bot settings. It includes machine-specific values (resolution, GPU string, audio device GUID). Back up your existing `plutonium_mp.cfg` before overwriting, and if you're setting this up on a different machine, merge just the `bots_*`/`ragdoll_*` lines by hand instead of a straight copy.

## Install — IW4X (MW2 2009)

IW4X is different: `autoexec.cfg`-based configs don't reliably execute on this client (confirmed through extensive testing — the mod's own passive fill loop can't self-seed bots from a config that never runs). `iw4-botwarfare-config.gsc` is a loose GSC script that hooks the map-init callback directly and force-seeds bots 5 seconds into every match, bypassing the broken exec path entirely. It also reads `bots_manage_fill` live so it always matches whatever total you've set, falling back to 16 if that dvar isn't populated yet.

1. Locate your MW2 install, e.g.:
   `~/.local/share/Steam/steamapps/common/Call of Duty Modern Warfare 2/`
2. Copy `iw4-botwarfare-config.gsc` into:
   `mods/mp_bots/scripts/mp/`
3. **Rename it to `autostart_bots.gsc`** — the filename matters, this is what IW4X's mod loader looks for in that folder.
4. Fully quit IW4X (not just leave the match — the client needs a genuine cold relaunch) and start a fresh match.

To change the target bot count later, edit `fillAmount = 16` inside the script — editing `bots_manage_fill` in any `.cfg` alone won't do anything on this client.
